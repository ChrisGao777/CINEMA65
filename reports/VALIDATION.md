# CINEMA 65 v0.8.3 · 阶段性验证结论

## 研发状态

**融合算法通过桌面测试，独立研究分支的 Android CI 编译、APK 签名和模型清单检查均通过；尚未发布新的 APK，也未在手机上验证实际画质。**

### 来自用户 v0.8.2 七次实机日志的基线

| 项目 | 七次实测 |
|---|---:|
| MiDaS Small 推理成功 | 7/7 |
| 平均深度推理耗时 | 157.6 ms |
| 平均完整分析耗时 | 685.6 ms |
| 人物蒙版可用 | 0/7（是否有真人需看原图判断） |
| 平均模型引导像素差 | 0.949/255 |
| 平均差异超过3级像素占比 | 12.3% |
| 原有策略自动选择 | 空间塑光 5，色彩叙事 2，主体细节 0 |

不能把“所有人物蒙版为空”视为人像模型故障：没有对应原图，不知道是否有人。

### 本次通过的工程测试

- 五组纯 Java 回归测试全部通过（稳定性、软蒙版、噪声抑制、条带一致性、候选评分质量门槛）。
- 两张真实摩洛哥原图在**无模型引导**条件下与 v0.8.2 做到了像素完全一致：RGB 均差 0，最大差 0。
- 具有合理人物分割和连续深度的**合成测试**产生了实际像素差异；恒定或噪声深度自动降权；无有效分割不会虚构人物。
- 桌面 CPU 640×480 代表性速度：传统 70.8 ms，融合 70.0 ms（JVM 测试结果不能用于预测 Android 手机上的耗时）。

### 仍未完成

- Android 17 小米手机真实推理、深度图是否保持几何正确以及调色实测；Gradle 构建已通过。
- 用**实际 MiDaS 和真实人物分割**输出进行视觉盲测及量化评估。
- 普适物体分割模型验证（独立物体、建筑、宠物、雕塑等）。
- RAW、高位深、ICC/EXIF、高像素恒定内存输出。

### 当前最重要的验收标准

不是让平均像素差变大，而是：

1. 真实主体/视觉落点被正确理解；
2. 亮度调整方向符合画面中已有光源；
3. 背景退后且保留纹理，不能凭空出现硬投影或光晕；
4. 人像在原有 v0.6+ 佳作中不能退步；
5. 对近似平手的三种候选方案，能清楚解释为什么保留基线。
